## 一张风景，一段只属于这趟旅途的短笺

- **去哪里，留一点惊喜。** 不选固定景点，在海岸、树林、雪景等虚构环境里遇见不同风景。
- **水彩画面，角色有迹可循。** 以角色与画风参考共同生图；内置三种服饰参考，也可导入自己的角色。
- **她寄信，你来收藏。** 图片与短笺保存在本地，可翻面阅读、导出 PNG 或 ZIP，更新不覆盖旧收藏。
- **一个落在桌面的木质小邮箱。** 可拖到任意已连接屏幕，松手后自然下落到底部，右键选择屏幕或放到底部；支持进度显示和来信提醒，不额外增加角色。
- **让等待有分寸。** 宠物主动询问的间隔可设置；只有你明确同意才出发，同一时间只进行一趟旅行。

## 安装与开始

在 Coopanion 扩展市场搜索 **旅行大肥鱼**，或按 npm 包名 `cortico-world-postcard` 安装。发布/收录状态以 npm 和市场实际结果为准。

1. 启用“旅行大肥鱼”，打开“配置引导”。
2. 配置生图服务：默认推荐 Seedream 5.0 Flash，也支持约定协议的其他云端/本地接口。
3. 宿主当前模型须支持 PNG 看图。看图和写信默认复用宿主，无需再配置 DeepSeek Key。
4. 选择角色参考，保存设置并应用重启，运行本地配置检查，再确认费用并完成“验证明信片制作”；通过后可以主动让她出发，或等她来问你。

详见[使用说明](USAGE.md)、[角色参考图要求](REFERENCE-REQUIREMENTS.md)与[本地生图接口](LOCAL-IMAGE-API.md)。桌面邮箱当前面向 Windows；目标宿主验证基线为 Coopanion 0.2.12 / World API 6，需要可用的独立 Electron 运行时。

## 旅行需要多少费用？

默认 Seedream 5.0 Flash 按 2026-10-28 [方舟官方标价](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)，通常一趟一张图约 **¥0.12**；若第一候选未通过、需要第二张，图片合计约 **¥0.24**，另加宿主模型看图、写信和检查用量。实际以服务账单为准。

可更换更便宜的模型，但画面细节、角色一致性和稳定性可能降低。本地生图需要自行部署兼容服务，仍可能有设备、电力及宿主模型费用。仅本地翻看、翻面和导出旧卡不调用生成 API。取消不能保证撤回已经提交的收费请求。

## 几个需要知道的小约定

旅行固定两小时，制作在旅途中提前进行；服务失败或超时可能延迟。自动检查图文明确矛盾，但不承诺每张绝无错误。场景是虚构风景，不保证真实地标还原。参考图发送给你选择的生图服务，成图交给宿主模型处理。密钥与个人收藏不随代码公开。

现有版本为实验版。邮箱可跨屏移动，记住所选屏幕及屏内位置；断开该屏后回到可见屏幕。主屏底部可请桌宠取信，副屏或悬空位置点击直接读信；桌宠跨屏取信尚不支持，部分真实混合缩放屏幕组合仍待验证。本版支持按原文查找旧旅行并核对来源，也支持在相关话题中低频自然回忆；是否提起由宿主模型判断，不保证每次触发，不写入宿主长期记忆。

### 邮箱与配置体验改进
邮箱水平拖动增加原生系统光标跟踪；文字提示仅悬停或点击后短暂显示，未读仍有信封标记。其他云端API的填写示例与协议限制见LOCAL-IMAGE-API.md。本次发布包含这些改进。

0.7.15 修复非整数显示缩放下的邮箱启动中断，并扩大邮箱点击、拖动区域。窗口位置上报失败不再阻断交互；排查时可查看邮箱 profile 内的 `window-report.json`（`reported` 为成功，`unavailable` 为上报失败）。

出发门槛：保存并重启后先做本地检查，再在配置引导明确确认计费、运行“验证明信片制作”。完整生图、看图、写信与审核通过后才允许新旅行和主动邀请；验证样张不创建旅行或加入收藏。验证结果在相同实际配置下长期有效；普通更新、重启、相同参考图重新导入或修改未使用服务密钥不要求重复验证。实际生图配置、当前服务密钥、参考图内容或所用宿主模型标识变化后须重新验证。旅行失败保留原验证，先处理原旅程，不重复收费测试。验证沿用现有最多两候选策略并消耗服务额度。历史通过不能保证未来外部API永不故障。


### 生图服务选择

默认仍为Seedream 5.0 Flash。配置引导新增千问图像编辑、Gemini原生协议，独立密钥与推荐配置预填；原有其他云端/本地JSON兼容通道继续保留。协议测试已覆盖双参考输入；当前开发环境的官方百炼千问已完成一次全流程制作验证，Gemini原生仍待真实云端验收。不能仅凭模型名称认定第三方服务兼容。

各服务填写方式、限制与官方依据见[生图服务接入](IMAGE-SERVICES.md)。切换后保存并重启World，完成制作验证才允许新旅行。不会自动替换已有配置或重画旧收藏。

### 查找以前的来信

可以让她“找找那张写到旧照片的明信片”或“看看最近收到的来信”。新增的旅行记录工具按标题与短笺原文检索，分页返回摘录及来源，读信可核对完整文字。只查旧卡不生图、不打开邮箱，也不会把信标记为已读；模型对话仍按宿主用量计费。

本版不做语义搜索或图片内容搜索，没有文字匹配不代表图片里一定没有相关内容。明确开发标记的卡片默认排除，也可要求查看演示记录。旧卡无需迁移或重新生成。

### S6.4 质量修正

新系列规划包含事件触发、角色反应、感受变化及各节点的朝向、动作、神态；生成时保留已冻结的构图变化。人物大小与镜头距离遵循故事节点景别，不设统一占比，跨卡只拒绝明显场景矛盾，小幅材质、视角变化不作为硬性失败。实际成图另行审核表现重复，最多两张候选预算保持不变。旧系列与收藏不追溯改写。开发隔离实例可启用 developmentTestMode，以固定5分钟验证服务、续程和界面，默认正式旅行仍为2小时。
