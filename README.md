# 旅行明信片 World

0.5.0 · 实验版。让宠物在现实时间里去远方走走，自动带回整幅水彩明信片与旅行短笺，形成永久本地收藏。

出发时不选地点，由宠物自己去远方走走。内部以八类虚构环境、27个场景方案组织画面；这些类别不代表固定目的地，也不作为收藏分类。新旅行固定2小时，同时一趟。类别与方案结合近期记录避重，候选不足时放宽。没有真实省市或景区对应，不承诺地标还原。图文由云端API自动生成并检查，正常使用不需要逐张人工审核。微风、声音、气味、感受和比喻允许保留，审核只拒绝明确文图矛盾。

## 安装与配置

见[USAGE.md](USAGE.md)。需要火山方舟Seedream5.0Flash（可换兼容模型），视觉可选宿主模型或独立DeepSeek；内置角色与画风参考，也可自选，需要World API6宿主；不需要本地模型、Python或本聊天常开。

密钥通过ctx.secret读取，放在部署.env或启动环境的POSTCARD_ARK_API_KEY、POSTCARD_VISION_API_KEY。参考图会传到火山方舟，成图会传到DeepSeek，按服务计费。包内不含密钥或私人配置；角色与画风默认参考图随包提供，素材权利说明见assets。图片/视觉代理分别配置；留空强制直连，不继承宿主全局代理。

本机目录安装包包含运行依赖，解压后选择其中的cortico-world-postcard目录安装；程序目录需保持原位。npm格式tgz也可安装。未向npm或扩展市场发布。

## 旅行与收藏

启用World后，在标准“远方来信”面板直接出发，或让Coo使用postcard_start。新旅行在旅途中提前制作，成品备妥后等待固定2小时归来交付；服务故障或超时可能延迟。完成后自动入库，按收到时间翻看、翻面、保存PNG原图和单趟ZIP。

World拥有旅行与收藏，不直接访问Persona Memory或其他World内部接口，不伪造共同经历。参考图由用户明确配置，首版美术测试使用固定蓝发鲸鱼装女孩，不会自动转换当前桌宠造型。离场动画、换装、行囊、真实路线、多宠物、云同步与社交不在本版范围。

## 数据与恢复

ctx.dataDir/postcard使用独立命名空间。单写入者锁、固定tripId/dueAt、出发固定参考/构图/策略、阶段检查点、原子收藏和完整SHA256校验；旧收藏不因升级或换图重算。v1/v2未完成旅程保留原提示和缓存恢复方式；v3出发即固定场景快照。新数据含旧版不支持的类别，降级应恢复升级前备份。

图片最多两张候选，每张合格图最多两版短笺。文案失败只改文字；远端结果不明的图片请求不盲目重发，需用户检查后显式确认，仍受两图上限约束。取消阻止迟到结果入库，已发送请求可能产生费用。完成通知与收藏分开，不保证跨进程严格一次投递。

列表按文件指纹缓存校验结果，变化即重新校验；显式读取和导出仍完整核对哈希。正式收藏离线可读；ZIP只包含图片、短笺和公开旅行元数据，不含提示词、服务记录或本机路径。

备份、磁盘失败、请求不明及升级说明见[RECOVERY.md](RECOVERY.md)。

## 宠物主动提议旅行
配置中可开关“允许宠物主动询问旅行”，设置“主动询问间隔（分钟）”，默认360分钟（6小时），最小1分钟、最长30天，立即生效。间隔到后宠物按自己的语气询问是否可以去旅行；未得到明确同意不会出发。已有未结束旅程、失败待处理或生成服务未连接时暂停，重新可用后计时。日程本地保存，重启不补发积压，只处理一次当前到期机会。修改间隔会重新计时。询问使用宿主原有模型对话，可能有少量文本费用；没有因询问而生成图片。表达和展示沿用宿主已有通道，没有新增离场动画或私有气泡接口。


0.2.4：旅行面板显示按真实起止时间计算的进度条。新旅行固定2小时，不再提供时长设置；旧config中的minutes值不影响新旅行，旧在途旅程的到期时间保持不变。100%仅表示等待结束，新版本在旅途中预制，通常到期直接交付。主动询问间隔仍可设置，和旅行时长无关。


## 使用宿主模型（0.3.0）
在配置中开启“使用宿主模型看图与写信”并重启本World。宿主当前模型须支持PNG；新旅行无需独立DeepSeek Key，仍须方舟生图密钥与两张参考图。任务进入主会话并消耗宿主额度，模型按任务工具返回JSON，正式审核和收藏仍由原流水线处理。忙碌时最长等待10分钟，超时在旅行面板手动“继续准备”，使用原图，不自动重生或转用独立收费API。关闭应用会中断等待，重开后失败任务手动继续，已完成阶段复用缓存。切换选项只影响新旅行，旧旅行仍使用出发时确定的通道；旧独立API旅程仍需要原Key。关闭宿主模式仍可使用原独立DeepSeek API。


## 0.4.0 默认与交付
默认生图模型为doubao-seedream-5-0-flash-260915；在配置页“生图模型ID”可填写其他支持双参考图、2K、PNG/base64输出的方舟模型或接入点ID。不是任意厂商API通用适配，仍使用方舟密钥/接口。画风路径留空使用内置开发水彩参考，可另选或恢复默认。新旅行在2小时内提前制作，成品只在归来时入册通知，提前备妥不提前发布；重启/离线保留待交付成品。API故障、超时或关机跨过归来时刻可能延迟，重开后补交，不承诺绝无延迟。旧在途旅程保持出发时冻结模型/参考/策略，不强制重画。


## 0.5.0 桌面旅行邮箱（R2）
默认开启独立桌面邮箱，只新增邮箱窗口，不创建、停用或替换桌宠。主屏底部显示与现有旅行共用的固定两小时进度；提前备妥的图片不公开，到期入藏后显示新信旗与未读数量。到期无成品如实显示待准备，可到收藏册检查或继续；关闭邮箱不取消旅行。收藏册中可点击“显示桌面邮箱”重新打开，完全关闭此功能可在配置关闭“显示桌面旅行邮箱”并重启World。

桌面邮箱仅验证Windows，需要可独立启动的Electron运行时：默认复用本机桌宠面板已安装的托管Electron，也可显式填写“邮箱Electron运行时路径”；不是Coopanion.exe。缺少运行时时不自动下载、不接管桌宠，旅行收藏册继续可用。桌面挂件本身不调用模型、不生图；不新增每趟API费用。R3的宠物靠近/开盖取信尚未加入。

点击邮箱或“收信”可打开最新未读来信，无未读时重读最近一张。图片实际载入或翻面显示短笺后才确认已读；读信失败不清除未读。未读和旅行/完成通知分开保存，重启保留，下一趟不覆盖。首次升级已有收藏按历史已读处理；mailbox.json损坏时暂停邮箱，不破坏正式收藏，可从收藏册阅读。桌面邮箱不提供出发入口，出发仍需用户在收藏册明确操作或向桌宠明确同意。

R2验证范围是正式World/旅行服务加测试WorldHost与原生邮箱的开发fixture，复用已有PNG并设置历史出发时间；不冒称完整Coopanion会话或真实等满两小时。多屏、系统缩放和恢复压力测试留R4，真实两小时验收留R5。
