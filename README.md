# 旅行明信片 World

0.7.0 · 实验版。桌宠在虚构远方旅行，把自己写给你的短笺和水彩明信片寄回家，形成永久本地收藏。Windows桌面邮箱已在Coopanion0.2.12验证；需要World API6。仍有素材公开分发权利待确认，当前只作本机开发和测试，不代表已获市场认证。

## 开始使用

安装并启用后打开“配置引导”。默认启用**宿主模型看图与写信**和**明信片生成能力**；开关本身不自动旅行或收费。准备生图服务、参考图和支持PNG的宿主模型后，用户点击出发，或明确同意桌宠的提议才开始。无需另配一份看图写信API。密钥只由宿主在部署环境保存，不包含在包或浏览器缓存中。

生图默认火山方舟Seedream5.0Flash，也可接入[本地兼容生图HTTP接口](LOCAL-IMAGE-API.md)。这不代表直接兼容任意本地软件或自动安装模型。角色和画风参考会发往所选生图服务，成图交由宿主当前模型处理；本地生图不等于看图写信也离线。

内置女仆装、冬装、店员装，默认冬装；用户导入图会复制到独立数据目录，在同一图库中并列选择。可下载[角色参考图要求](REFERENCE-REQUIREMENTS.md)，将其和原图交给自己的Agent整理。默认使用内置水彩参考，更改只影响新旅行。

## 费用与画面

按[方舟官方计费](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)2026-10-28标价，默认Flash图片约0.12元/张，正常一趟1张；候选拒绝后第2张约使图片部分达到0.24元，另加宿主模型看图/短笺/检查用量。实际依服务账单和你的费率结算。取消不保证撤销已发请求。可更换较便宜的兼容模型并填写单张估价，但角色一致性、细节与稳定性可能降低。未知远端结果不盲目重试；最多两张候选，文字失败优先只改文字。

出发不选择地点，内部八类虚构环境与27个场景方案避重，不对应真实省市或景点。生成后自动检查明确图文矛盾，感受、温度、声音与比喻允许适度模糊；不要求逐张人工审校，但有限样本不能保证零错误。

## 旅行、邮箱与收藏

正式新旅行固定2小时，同一时间只能一趟；旅途中提前制作，到期后入藏，服务失败可能延迟。邮箱只显示来信提醒，用户轻点才让原桌宠跑去取信、开盖浮卡并打开预览；用户收下或翻面才确认已读。邮箱仅水平拖动、始终落地、记住位置，原桌宠在前，不新增角色。目前固定主屏，不承诺跨副屏取信。

连点合并请求；已取出的信再次查看仅本地打开，不重复唤醒模型。尚未完成的暂缓请求有60秒保护。侧栏用宿主公开状态灯显示配置、宿主看图能力与旅行/未读/错误状态；“已配置”不等于已验证网络连通。

已经收到的图片、短笺与元数据独立保存在ctx.dataDir/postcard/collection；更换模型/参考和升级不重画、不覆盖收藏。显式读取与导出核对SHA256，旧信可离线翻看/保存PNG/ZIP。更新须保留原数据目录，卸载扩展不应手动删除收藏；降级或迁移前备份。详见[恢复说明](RECOVERY.md)。

## 安装与验证边界

见[使用说明](USAGE.md)。尚未发布npm/市场，当前本机目录链接安装需保留目录原位，不能把源码包当作包含Electron运行时的完整应用。独立邮箱自动查找已安装的Electron；不存在时收藏册仍可用。

World只管理外部旅行与收藏，不访问Persona Memory或其他World内部handler；取信通过事件和公开pet_move_to协议。核心回归及新增0.7测试见VALIDATION.md。R5已通过加速体验，完整真实两小时验收未完成；屏幕热插拔/主屏切换和所有扩展组合仍未穷尽验证。
